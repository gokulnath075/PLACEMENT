Excel File Column Guidelines

Your Excel file should contain a header row with columns similar to:

Register Number | Student Name | Department | Email | Student Mobile | Parent Mobile | DOB | Aadhar Number | Gender | Address | Batch | Passout Year | Arrears History | No. of Arrears | Sem 1 % | Sem 2 % | Sem 3 % | Sem 4 % | Sem 5 % | Sem 6 % | X % | XII % | ITI
  • Register Number is used as the unique identifier for each student.
  • Student Photos: If photos are placed in the media/student_photos/ directory named with the student's Register Number (e.g. 24213946.jpg), they will be automatically linked to the profile!
